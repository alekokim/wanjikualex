# Wanjiku Alex | Personal Portfolio

A responsive personal portfolio website for Wanjiku Alex, an Information Technology student in Kenya. It introduces my background, education, technical skills, projects, and interests in software development, web development, and data analysis.

## Features

- Sections for About, Skills, Projects, Education, Career Interests, and Contact
- Responsive navigation with a mobile menu
- Animated introduction text and scroll-reveal effects
- Back-to-top button and automatically updated copyright year

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

No dependencies or build tools are required. Clone the repository and open `index.html` in a browser.

Alternatively, run a local server from the project folder:

```powershell
py -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This static website can be hosted for free with GitHub Pages; no build step is required.

1. Push the project files to your GitHub repository.
2. In the repository, open **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.

GitHub Pages publishes a project site at `https://<username>.github.io/<repository-name>/`. For example, with the GitHub username `alekokim` and a repository named `wanjikualex`, the URL will be `https://alekokim.github.io/wanjikualex/`. Keep the HTML, stylesheet, JavaScript, and image files in the repository so the whole site loads correctly.
